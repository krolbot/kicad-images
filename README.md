# KiCad container images

Исходники образов KiCad для графического редактора и автоматизированной работы через MCP.

## Образы

- `ghcr.io/krolbot/kicad-mcp:10.0.6-0.21.1-fr2.1.0-tools1` — официальный KiCad 10.0.6, MCP server 0.21.1, Freerouting 2.1.0, KiKit, PcbDraw, SKiDL, WireViz и KiCost.
- `ghcr.io/krolbot/kicad-gui:10.0.3-tools3` — браузерный редактор на основе LinuxServer.io KiCad 10.0.3, KiKit и PcbDraw.

Каждая сборка также публикует тег `sha-<полный SHA коммита>` и OCI-метку `org.opencontainers.image.revision`. Образы собираются в GitHub Actions; автоматического развёртывания нет.

Видимость пакетов GHCR задаётся отдельно от видимости GitHub-репозитория. Публичный исходный код сам по себе не означает, что образ уже доступен без авторизации.

## MCP

MCP запускается по stdio командой `mcp-server-kicad`. Сервисный контейнер по умолчанию работает от UID/GID 1000 и ожидает рабочие проекты в `/projects`. Для постоянного хранения подключите этот каталог как том; доступ к Docker socket и внешний сетевой порт MCP не нужны.

При сборке `mcp_smoke.py` открывает настоящую MCP-сессию, проверяет наличие основных методов, версию KiCad и чтение стандартного символа резистора. Проверка не меняет пользовательские проекты.

Графические плагины устанавливаются через KiCad Plugin and Content Manager в постоянный каталог `/config`. Они не устанавливаются этим образом автоматически и не становятся новыми MCP-методами. Библиотеки, нужные редактору и MCP одновременно, следует хранить вместе с проектом и подключать проектными таблицами библиотек.

## Сборка

```sh
docker build -t kicad-mcp -f Dockerfile .
docker build -t kicad-gui -f Dockerfile.gui .
```

Базовые образы закреплены по digest, версии дополнительных программ указаны в Dockerfile. Конфигурация конкретного сервера, учётные данные и рабочие проекты в этот репозиторий не входят.
